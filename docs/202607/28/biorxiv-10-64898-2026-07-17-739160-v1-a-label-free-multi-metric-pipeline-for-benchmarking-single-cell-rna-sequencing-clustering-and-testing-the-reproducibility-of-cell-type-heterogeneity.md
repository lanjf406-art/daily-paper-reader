## 摘要
从单细胞转录组数据中发现亚群只有在可重复的情况下才有意义，然而聚类通常只使用一种方法在一个嵌入上进行，很少进行测试。我们提出了一种无标签、多指标的流程，该流程将聚类重新定义为一种可审计、方法盲的决策，并区分了通常被混淆的两种稳定性概念：在细胞重采样（bootstrap）下的可重复性和在重新嵌入（重新训练表示）下的可重复性。该流程使用五个非冗余的质量指标评估跨聚类数的七种聚类配置。作为小鼠视网膜图谱的整个数据集对照，它在无标签的情况下以96.3%的准确率（调整兰德指数，ARI = 0.91）恢复了八种细胞类型的注释。然后，我们在两种具有相反真实情况的细胞类型上验证了发现模式。对于具有明确亚型的双极细胞，该流程接受子结构：跨嵌入的可重复性随聚类数上升至一个高平台（在约15个已知双极细胞亚型附近，平均成对ARI约为0.93），同时质量指标也同步改善。对于被视为同质的视杆细胞，它拒绝过度聚类：指标选择的分区通过了bootstrap稳定性检查，但当重新训练嵌入时不可重复（平均成对ARI = 0.69），且指标不随聚类数改善。在合成数据上，该测试能够发现低至5%亚群的真实结构，同时拒绝零数据（高灵敏度和特异性）。

因此，仅靠bootstrap稳定性不足以证明亚群的存在；跨嵌入测试能够区分真实子结构与过度聚类，并适用于任何细胞类型，作为单方法、单嵌入聚类的可重复替代方案。

## Abstract
A discovered sub-population from single-cell transcriptomic data is only meaningful if it is reproducible, yet clustering is usually done with one method on one embedding and rarely tested. We present a label- free, multi-metric pipeline that reframes clustering as an auditable, methods-blind decision and separates two notions of stability that are commonly conflated: reproducibility under cell resampling (bootstrap) and reproducibility under re-embedding (retraining the representation). The pipeline evaluates seven clustering configurations across cluster counts using five non-redundant quality metrics. As a whole- dataset control on a mouse retinal atlas, it recovers an eight-cell-type annotation at 96.3% accuracy (adjusted Rand index, ARI = 0.91) without labels. We then validate the discovery mode on two cell types with opposite ground truth. On bipolar cells, which have well-established subtypes, the pipeline accepts the sub-structure: across-embedding reproducibility rises with cluster number to a high plateau (mean pairwise ARI [~]0.93 near the [~]15 known bipolar subtypes), with quality metrics improving in parallel. On rod photoreceptors, treated as homogeneous, it rejects over-clustering: the metric-selected partition passes a bootstrap-stability check but is not reproducible when the embedding is retrained (mean pairwise ARI = 0.69), and the metrics do not improve with cluster number. On synthetic data, the test recovers real structure down to a 5% subpopulation while rejecting null data (high sensitivity and specificity).

Bootstrap stability alone is therefore insufficient evidence for sub-population; the across-embedding test discriminates real sub-structure from over-clustering and applies to any cell type as a reproducible alternative to single-method, single-embedding clustering.
